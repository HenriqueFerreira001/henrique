# Skill de Marketing

Esta skill equipa o agente com um fluxo de trabalho estruturado para todas as tarefas de marketing digital.

## Quando usar esta skill

Ative automaticamente quando o usuário:
- Pedir análise de campanha (Meta Ads, Google Ads, TikTok, e-mail, etc.)
- Quiser criar ou editar anúncios, copies, headlines, CTAs
- Precisar de estratégia de funil, segmentação de público ou calendário de conteúdo
- Compartilhar métricas (CTR, ROAS, CPC, CPM, taxa de conversão)
- Pedir sugestão de criativo, roteiro de vídeo ou texto para stories/reels

---

## 1. Análise de Campanha

Ao receber dados de campanha, siga este roteiro:

### Métricas essenciais para avaliar

| Métrica | O que indica | Referência saudável |
|---|---|---|
| CTR | % de cliques sobre impressões | > 1% (display) / > 2% (search) |
| CPC | Custo por clique | Depende do nicho |
| CPM | Custo por 1.000 impressões | Comparar com histórico |
| ROAS | Retorno sobre gasto em anúncio | > 3x (mínimo viável) |
| Taxa de conversão | % que comprou/se cadastrou | > 1% (e-commerce) |
| CPA | Custo por aquisição | Menor que o LTV do cliente |
| Frequência | Quantas vezes o mesmo usuário viu | < 3 (após isso, cansa) |

### Como apresentar a análise

1. **Resumo executivo** — o que está bem, o que está mal (2-3 linhas)
2. **Métricas detalhadas** — tabela com os números
3. **Diagnóstico** — causa raiz dos problemas identificados
4. **Plano de ação** — 3 a 5 ajustes concretos com prioridade (Alta/Média/Baixa)

## 2. Criação de Campanha

Ao criar uma campanha do zero, colete (ou assuma) estas informações:

- **Produto/Serviço:** o que está sendo vendido
- **Público-alvo:** idade, localização, interesses, nível de consciência (frio/morno/quente)
- **Objetivo:** tráfego, geração de leads, vendas, engajamento, awareness
- **Plataforma:** Meta, Google, TikTok, e-mail, WhatsApp, etc.
- **Orçamento diário/total**
- **Tom de voz:** formal, descontraído, urgente, aspiracional

### Estrutura de entrega

```
## Campanha: [Nome da campanha]

**Objetivo:** [conversão / lead / awareness]
**Plataforma:** [Meta Ads / Google / etc.]
**Público:** [descrição do segmento]
**Orçamento sugerido:** R$ X/dia

---

### Anúncio 1 — [Ângulo: ex. Dor/Problema]
**Headline:** [título principal]
**Copy:** [texto do anúncio]
**CTA:** [botão de ação]
**Sugestão de criativo:** [descrição da imagem/vídeo ideal]

### Anúncio 2 — [Ângulo: ex. Benefício/Resultado]
...

### Anúncio 3 — [Ângulo: ex. Prova Social]
...
```

## 3. Fórmulas de Copy

Use estas estruturas comprovadas:

**AIDA** — Atenção → Interesse → Desejo → Ação
**PAS** — Problema → Agitação → Solução
**4U** — Útil, Urgente, Único, Ultra-específico
**BAB** — Before (antes) → After (depois) → Bridge (como chegar lá)

### Headlines de alto desempenho (modelos)

- "Como [resultado desejado] em [tempo] sem [objeção principal]"
- "[Número] formas de [benefício] que [público] não conhece"
- "Pare de [dor] — descubra como [solução] em [tempo]"
- "A verdade sobre [tema] que ninguém te contou"
- "[Resultado] garantido ou [promessa de segurança]"

## 4. Estratégia de Funil

### Funil simples (3 etapas)

```
TOPO (Awareness)
→ Conteúdo educativo, vídeos curtos, posts de valor
→ Objetivo: alcançar pessoas que não conhecem a marca

MEIO (Consideração)
→ Depoimentos, cases, comparativos, webinars
→ Objetivo: nutrir quem já interagiu

FUNDO (Conversão)
→ Oferta direta, desconto, urgência, garantia
→ Objetivo: fechar a venda / capturar o lead
```

### Retargeting

- Quem viu o anúncio mas não clicou → mude o criativo
- Quem clicou mas não comprou → mostre prova social + oferta
- Quem comprou → upsell, cross-sell ou programa de indicação

## 5. Calendário de Conteúdo (modelo semanal)

| Dia | Tipo de conteúdo | Objetivo |
|---|---|---|
| Segunda | Dica educativa | Valor / Autoridade |
| Terça | Bastidor / processo | Humanização |
| Quarta | Depoimento / case | Prova social |
| Quinta | Oferta ou CTA | Conversão |
| Sexta | Conteúdo leve / entretenimento | Engajamento |
| Sábado | Reposta a dúvidas / interação | Relacionamento |
| Domingo | Inspiração / motivação | Conexão emocional |

---

## 6. Checklist antes de lançar qualquer campanha

- [ ] Pixel/tag de rastreamento instalado e testado
- [ ] Página de destino carrega em menos de 3s no celular
- [ ] Copy revisado (sem erros, CTA claro)
- [ ] Pelo menos 3 variações de criativo para teste A/B
- [ ] Públicos configurados corretamente (não sobrepostos)
- [ ] Orçamento e datas de início/fim definidos
- [ ] UTMs configurados para rastrear a fonte no Analytics
- [ ] Meta de resultado definida (ex: 50 leads a R$10 cada)
